정보보안 실습용

GitHub Secret에서 가져왔더라도 정적 페이지를 만들 때 HTML이나 JavaScript에 넣으면 방문자에게 그대로 전달됩니다. 

불러오는 중...

화면에서 숨기거나 난독화해도 보호되지 않습니다. 방문자는 개발자 도구, 페이지 소스, 네트워크 기록에서 값을 확인할 수 있습니다.

실제 비밀 키는 프론트엔드에 넣지 말고 서버에서만 사용해야 합니다.

GitHub Pages에서는 어떻게 노출될까요?

Secret 저장소 자체는 비공개입니다. 문제는 빌드할 때 그 값을 정적 파일에 복사하는 순간 시작됩니다.

1단계 · 비공개 GitHub Secret

저장소 설정에 API_KEY를 보관합니다. 여기까지는 방문자가 볼 수 없습니다.

→
2단계 · 빌드 GitHub Actions

Secret 값을 HTML 또는 JavaScript 코드 안에 삽입해 정적 파일을 만듭니다.

→
3단계 · 공개 GitHub Pages

완성된 파일 전체가 방문자의 브라우저로 전달됩니다. 삽입된 키도 함께 공개됩니다.

핵심: GitHub Secret은 빌드 전까지만 비밀입니다. 브라우저로 전달되는 결과물에 들어간 값은 더 이상 Secret이 아닙니다.
