# San Code Highlight 개인정보처리방침

**최종 수정일: 2026년 8월 12일**

San Code Highlight(이하 "본 부가기능")는 Google 문서 및 Google 프레젠테이션에서 소스 코드에 구문 강조 서식을 적용하는 도구입니다. 본 방침은 본 부가기능이 사용자 정보를 어떻게 다루는지 설명합니다.

## 1. 수집하는 정보

**본 부가기능은 어떠한 개인정보도 수집하지 않습니다.**

- 사용자의 이름, 이메일 주소, 계정 정보를 수집하지 않습니다.
- 문서 내용을 수집·저장·기록하지 않습니다.
- 사용 기록, 분석 데이터, 통계를 수집하지 않습니다.
- 쿠키 및 이에 준하는 추적 기술을 사용하지 않습니다.

## 2. 접근 권한과 그 이유

본 부가기능은 다음 권한을 요청합니다.

| 권한 | 용도 |
|---|---|
| `documents.currentonly` | 현재 열려 있는 Google 문서의 텍스트를 읽고 글자 색·글꼴을 변경 |
| `presentations.currentonly` | 현재 열려 있는 Google 프레젠테이션에 대해 위와 동일한 작업 수행 |
| `script.container.ui` | 문서 내 사이드바 및 메뉴 표시 |

앞의 두 권한은 이름 그대로 **현재 열려 있는 문서 하나에만** 적용됩니다. 본 부가기능은 사용자의 Google 드라이브에 있는 다른 파일에 접근할 수 없습니다.

## 3. 정보의 처리 방식

모든 처리는 Google Apps Script 환경, 즉 **사용자의 Google 계정 내부에서** 실행됩니다.

- 문서 내용이 외부 서버로 전송되지 않습니다.
- 개발자를 포함한 제3자가 문서 내용에 접근할 수 없습니다.
- 본 부가기능은 외부 네트워크 요청을 전혀 수행하지 않습니다.
- 처리 결과(적용된 글자 색)는 사용자의 문서에만 저장됩니다.

## 4. 제3자 제공

본 부가기능은 수집하는 정보가 없으므로, 제3자에게 제공하거나 판매하는 정보도 없습니다. 광고 네트워크 및 분석 서비스와 연동되어 있지 않습니다.

## 5. 데이터 보관 및 삭제

본 부가기능은 데이터를 보관하지 않으므로 삭제할 데이터가 존재하지 않습니다. 부가기능을 제거하려면 Google 문서에서 **확장 프로그램 → 부가기능 → 부가기능 관리**로 이동해 제거하면 됩니다. 제거 후에도 이미 문서에 적용된 서식은 그대로 유지됩니다.

## 6. Google API 서비스 사용자 데이터 정책

본 부가기능의 Google API 사용은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)의 제한 사용 요건(Limited Use requirements)을 준수합니다.

## 7. 아동의 개인정보

본 부가기능은 아동을 포함한 어떠한 사용자로부터도 개인정보를 수집하지 않습니다.
