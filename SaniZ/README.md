# SaniZ 사용법 (최신 버전: v1.3)

화면을 확대하고 그 위에 그림 · 글씨를 쓰는 도구예요. 화면 일부를 오려 **항상 맨 위에 띄워 두는 게시 모드**도 있습니다. (Windows 10/11 64비트 전용)

**⬇️ [SaniZ v1.2 다운로드](https://github.com/sanewee/public/raw/refs/heads/main/SaniZ/SaniZ_v1.3.zip)**

`SaniZ.exe`를 더블클릭하면 트레이에 상주하고, 아래 단축키로 바로 씁니다. 설치 불필요, 별도 DLL 없이 단독 실행됩니다.

> ⚠️ **처음 실행 시 파란 경고창이 뜨면** — "Windows에서 PC를 보호했습니다" 창은 서명되지 않은 개인 제작 프로그램이라 뜨는 정상 안내입니다(바이러스 아님).
> **"추가 정보"** → **"실행"** 을 누르면 됩니다.

<br>

## 🔑 모드 켜고 끄기

| 키 | 기능 |
|----|------|
| `Alt + ~` | **게시 모드** 켜기 / 끄기 |
| `Alt + 1` | **확대 모드** 켜기 / 끄기 |
| `Alt + 2` | **판서 모드** 켜기 / 끄기 |
| `Alt + 3` | **편집 모드** 켜기 / 끄기 (판서 ↔ 편집 전환, 그린 내용 유지) |
| `Ctrl + S` | 현재 화면을 이미지(PNG)로 저장 |
| `Esc` | 종료 |

`Ctrl + S`는 확대 · 판서가 켜져 있는 동안에만 잡습니다. 평소에는 다른 프로그램의 저장 단축키를 가로채지 않아요.

<br>

## 📌 게시 모드 (`Alt + ~`)

화면의 한 부분을 오려서 **항상 맨 위에 떠 있는 조각**으로 만듭니다. 참고 자료를 옆에 두고 수업할 때 씁니다.

- 켜면 화면이 어두워지고 **커서를 따라 "드래그를 통해 게시할 영역을 지정할 수 있습니다."** 안내가 붙어 다녀요.
- **드래그** → 그 영역이 조각으로 떠오릅니다. 한 번 지정하면 게시 모드는 자동으로 꺼져요.
  - 모드가 꺼지는 건 "이제 더 못 붙인다"는 뜻일 뿐, **떠 있는 조각은 그대로 유지**됩니다.
  - 더 붙이려면 `Alt + ~`를 다시 누르세요. 여러 개 붙일 수 있습니다.
- **조각은 어떤 모드에서도 항상 화면 맨 위에 있습니다.** 확대 · 판서 · 편집 모드로 전환해도 가려지지 않아요.
- 조각 위에서 —
  - **드래그** → 위치 이동
  - **마우스 휠** → 크기 조절 (조각을 한 번 클릭해 활성화한 뒤가 확실합니다)
  - **우클릭** → 그 조각 삭제
- 트레이 아이콘 우클릭 → **"게시된 조각 모두 닫기"** 로 한 번에 정리.

<br>

## 🔍 확대 모드 (`Alt + 1`)

- **마우스 이동** → 커서를 그대로, 지연 없이 따라갑니다.
- **마우스 휠** → 확대 배율 조절
- **좌클릭** → 그 화면 그대로 멈추고 **판서 모드로 자동 전환**

<br>

## ✏️ 판서 모드 (`Alt + 2`)

커서 옆에 **지금 고른 펜 색과 단축키 글자가 배지로 표시**됩니다. (지우개일 땐 `E`, 텍스트 대기 중엔 `T`)

**그리기**

| 입력 | 기능 |
|------|------|
| 드래그 | 자유 곡선 |
| `Ctrl` + 드래그 | 사각형 (테두리) |
| `Ctrl + Shift` + 드래그 | 채운 사각형 |
| `Shift` + 드래그 | 직선 |

**색 · 텍스트 · 지우개 · 배경**

| 키 | 기능 |
|----|------|
| `R` / `G` / `B` / `Y` / `I` | 펜 색 (빨강 / 초록 / 파랑 / 노랑 / 아이보리) |
| `T` | 텍스트 입력 (누른 뒤 위치 클릭 → 입력, `Shift+Enter` 줄바꿈, `Enter` 완료) |
| `S` | 숫자 스탬프 (누른 뒤 찍을 자리 클릭. 번호는 자동으로 다음 번호) |
| `E` | 지우개 켜기 / 끄기 |
| 마우스 휠 | 펜 굵기 · 글자 크기 · 지우개 크기 즉석 조절 |
| `K` / `W` | 어두운 / 밝은 배경 |
| `Ctrl + Z` | 마지막 동작 되돌리기 (한 단계, 다시 누르면 복구) |
| `Ctrl + E` | 판서 내용 전체 삭제 |

**지우개는 지나간 부분만 지웁니다.** 곡선이든 사각형이든 채운 사각형이든 텍스트든, 지우개 원이 지나간 픽셀만 없어지고 나머지는 그대로 남아요. 지우개 범위는 회색 원으로 표시되고, 커서 옆 배지에 `E` 가 뜹니다.

**마우스 휠로 크기를 그때그때 바꿉니다.** 그냥 그릴 땐 펜 굵기, `T`·`S` 를 누른 뒤엔 글자·스탬프 크기, 지우개일 땐 지우개 크기. 커서 옆 배지에 지금 값이 같이 뜹니다 (`R 10`, `T 50`, `S 3`, `E 60`). 이 값은 그 판서 세션에만 적용되고 설정에 저장되지는 않아요.

**숫자 스탬프(`S`)** — 누르고 찍을 자리를 클릭하면 ①②③ 순서대로 번호가 박힙니다. `Ctrl+Z` 로 취소하면 번호도 함께 되돌아가서, 다시 `S` 를 누르면 방금 그 번호부터 이어집니다. `Ctrl+E` 로 전부 지우면 1번부터 다시 시작해요.

`T` 로 글자를 한 번 입력하고 `Enter` 로 끝내면 곧바로 펜 상태로 돌아옵니다.

### 글 쓰는 중 커서 이동

- **← →** 로 한 글자씩, **↑ ↓** 로 윗줄 · 아랫줄, **Home / End** 로 줄의 처음 · 끝
- **글자 사이를 클릭**하면 그 자리로 커서가 갑니다 (글 바깥을 클릭하면 입력이 마무리됩니다)
- **Backspace** 는 커서 앞 글자, **Delete** 는 커서 뒤 글자
- 글자는 커서 자리에 끼워 넣어집니다

한글은 조합이 끝나지 않은 상태(`강`을 치는 중에 `가`가 떠 있는 상태)에서 커서를 옮기거나 `Delete` 를 누르면 **그 상태로 확정된 뒤** 처리됩니다. 한글 워드프로세서와 같은 방식이에요.

판서 · 편집 중에는 우클릭으로 창이 닫히지 않습니다. 실수로 작업이 날아가지 않게 막아둔 거예요. 나갈 때는 `Esc`.

### 한글 입력

**조합 중인 글자가 그 자리에 바로 그려집니다.** 화면 좌측 상단에 흰 입력창이 따로 뜨지 않아요.

- 조합 중인 글자는 밑줄로 표시되고, 확정되면 밑줄이 사라집니다.
- 한자 · 이모지 변환 후보 목록도 커서 옆에 뜹니다.
- 텍스트 입력 중이 아닐 때는 IME를 떼어 두기 때문에, **한글 상태에서도 `R`·`G`·`T` 같은 단축키가 그대로 먹습니다.**

<br>

## ✂️ 편집 모드 (`Alt + 3`)

판서 모드에서 그린 뒤 `Alt+3`으로 전환하면, 배경은 그대로 두고 **그려둔 펜·텍스트만** 옮길 수 있어요. 다시 `Alt+3`을 누르면 판서 모드로 돌아가고 그린 것은 유지됩니다.

- **드래그** → 사각형 영역 선택 (점선)
- **선택 영역 안을 드래그** → **사각형 안에 들어온 부분만** 이동합니다.
  사각형이 도형을 가로질러도 안에 든 부분만 잘라서 움직이고, 바깥은 제자리에 남아요.
- `Alt + 2` 로 판서 모드에 돌아가도 그린 내용은 그대로 유지됩니다.

<br>

## ⚙️ 설정

트레이 아이콘 **더블클릭** → 설정 창. (트레이 우클릭 → "설정" 도 같습니다)

- **단축키** — 게시 · 확대 · 판서 · 편집 · 화면 저장. 칸을 누르고 원하는 키를 그대로 누르면 됩니다 (`Backspace` 로 지움)
- **그리기** — 확대 배율(`2.0` 처럼 소수로 입력, 기본 2.0), 펜 굵기(기본 10), 지우개 크기, 텍스트 크기(**포인트** 단위, 기본 50 — 글꼴 대화상자와 같은 단위로 서로 연동됨), 텍스트 글꼴
- **색** — 펜 5색(R G B Y I), 배경 2색(K W). 단추에 해당 단축키 글자가 적혀 있습니다
- **기타** — Windows 시작 시 자동 실행 (관리자 권한 없이 현재 사용자만)

글꼴은 **직접 설치한 글꼴을 포함해 시스템에 있는 모든 글꼴**에서 고를 수 있습니다.

바꾼 설정은 레지스트리(`HKCU\Software\SaniZ`)에 자동 저장됩니다. **기본값** 단추로 처음 상태로 되돌릴 수 있고, 다른 프로그램이 이미 쓰는 단축키를 지정하면 등록 실패한 항목을 알려줍니다.

`Tab` 으로 항목 이동, `Esc` 로 닫기, `Enter` 로 확인이 됩니다.

<br>

> 💡 확대 · 판서를 켠 순간의 화면이 "정지"됩니다. 안 쓸 때는 트레이에 조용히 있으면서 메모리를 거의 쓰지 않아요 (타이머 · 폴링 없음).

### 메모리 사용량

화면 크기만큼의 이미지를 다루는 도구라 **켜져 있는 동안에만** 메모리를 씁니다. 끄면 즉시 돌려줍니다.

| 상태 | FHD | QHD | 4K |
|---|---|---|---|
| 트레이 대기 | 0 | 0 | 0 |
| 확대 모드 | 8 MB | 14 MB | 32 MB |
| 판서 — 그리기 전 | 24 MB | 43 MB | 96 MB |
| 판서 — 그린 뒤 | 32 MB | 57 MB | 129 MB |
| 게시 영역 지정 중 | 24 MB | 42 MB | 95 MB |

필요할 때만 버퍼를 만들도록 해서, 확대만 쓸 경우 4K 기준 **129 MB를 아낍니다.**
